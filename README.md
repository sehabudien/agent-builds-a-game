An entry for the make.fun bounty [The agent builds a game from one prompt](https://make.fun/bounty/post-x-the-agent-builds-a-game-from-20261122-1709).

## The video

`game-video.mp4` (22 seconds, 1280×720) shows an AI agent building a tiny
browser game from **one prompt** while you watch:

1. **The prompt** — "Build me a tiny browser game where a ghost collects
   coins and dodges spikes — arrow keys to move, 60 seconds, score in the
   corner."
2. **The agent working** — the game code appearing line by line.
3. **The finished game running** — real gameplay footage of Ghost Coin Dash,
   captured in a real browser with real arrow-key input.
4. **The call** — "It works. One prompt. Come build on make.fun", ending with
   make.fun's referral end card carrying the referral code `dkcwyg48`.

## The game

`game.html` is the game itself — open it in any browser. Fly the ghost with
the arrow keys (or WASD), collect the magenta coins, dodge the red spikes
and the patrol ball. 60 seconds, 3 lives, score in the corner.
